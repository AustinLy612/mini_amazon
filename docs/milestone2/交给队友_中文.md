# Carts M2 交接（Ziyi Shen）

## 当前代码与团队命名

以 Google Docs 中 Leyang Han 的 USER、Tiancheng Yu 的 PRODUCT 设计为依据：
- Orders：buyer_name_snapshot、shipping_address_snapshot。
- OrderItems：id 主键、product_name_snapshot、unit_price > 0、fulfilled_at；UNIQUE(order_id,product_id,seller_id)。
- CartItems：(buyer_id,product_id,seller_id) 主键，分别引用 Users/Products，不引用 Inventory。
- Inventory：(seller_id,product_id,quantity)，允许移除记录；购物车 LEFT JOIN 库存，缺失时保留商品并显示不可购买。
- 价格来自 Products.price，必须为正，不使用 Products.available 或 Inventory.active 判断购物车可购买状态。

Users 的 password_hash、is_seller、必填 address，以及 Products 的分类/描述等完整迁移由对应同学负责。本次不替他们重写登录/商品模块；现有骨架仍保留旧 password/available 等字段。

## 运行与迁移

测试环境：课程容器内 poetry install --no-root；poetry run python -m unittest discover -s tests -v。

最新版已验证数据库为 mini_amazon_m2_verify_aligned_20261008。启动：

```bash
DB_NAME=mini_amazon_m2_verify_aligned_20261008 poetry run flask run --host 0.0.0.0 --port 8080
```

新空库：先 db/create.sql，再从 db/data 工作目录运行 ../load.sql，最后 db/carts_schema.sql、db/carts_demo.sql。脚本各运行一次。

旧版 Carts 库：先备份，审查 db/migrate_carts_m2_contract.sql，再运行一次；不能重复运行新建表脚本。迁移会重命名快照字段、新增订单行 id、调整外键/正数价格约束；旧 inactive 库存设为 0，防止忽略旧 active 字段后重新可售。不会迁移 Users 的完整新 schema。不要把旧脚本和新脚本同时运行。

本次原有开发数据库未迁移；验证只使用单独测试库。关于测试边界详见 VALIDATION.md。
